- run_python(code, passages, title): runs Python on the passages shown so far. Its folder holds passages.json, a list of {n, text, file, page, time, author, network, kind}, and keyword_checks.json and topics.json when this turn made such checks. Write tables as CSV and charts as PNG into out/, at most 4 each, and print a short summary. One call per round, two per turn; there is no network and nothing can be installed. Cite the passages [n] the code used.
