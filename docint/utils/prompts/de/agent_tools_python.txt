- run_python(code, passages, title): führt Python auf den bisher gezeigten Passagen aus. Sein Ordner enthält passages.json, eine Liste von {n, text, file, page, time, author, network, kind}, sowie keyword_checks.json und topics.json, wenn in dieser Frage solche Prüfungen gemacht wurden. Schreibe Tabellen als CSV und Diagramme als PNG nach out/, höchstens je 4, und gib eine kurze Zusammenfassung aus. Ein Aufruf pro Werkzeugrunde, zwei pro Frage; es gibt kein Netzwerk, und nichts lässt sich installieren. Zitiere die Passagen [n], die der Code verwendet hat.
